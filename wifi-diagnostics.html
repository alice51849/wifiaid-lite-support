Wi-Fi diagnostics on iPhone: find out where the connection is actually failing

When the internet is down, the router usually gets the blame. The real problem could be Wi-Fi, DNS, your internet provider, or just one website. Where a connection can break

Between your iPhone and a website there are several hops, and a failure at any of them just feels like "the internet is slow". Good diagnostics rule them out one at a time:

CheckWhat it tells youTypical symptom when it fails
DNSWhether names resolve to IP addressesConnected to Wi-Fi, but pages spin forever
TCPWhether a connection to the server opensSome apps fail, sometimes
TLSWhether the secure connection completesPages stall halfway or show security errors
TTFBHow long the server takes to start respondingEvery tap feels delayed
StabilityHow much latency varies across samplesLooks connected, feels laggy
IPv4 / IPv6Whether both address types workCertain services fail more than others

How to run a network test with WiFi Aid Lite

  1. Run a Check. One tap checks Wi-Fi, DNS and the wider internet.
  2. Read the evidence. DNS, TCP, TLS, TTFB, HTTP, Direct IP, IPv4 and IPv6 are listed item by item.
  3. Use Deep Check for flaky connections. It gathers more evidence and stability samples, so you can see when the connection looks unstable.
  4. Check a Website. Test one site to see whether the problem is that site or the wider internet.
  5. See the connected node. With precise location on, the app identifies this Wi-Fi and the current node.
  6. Keep a history. Private records are stored only on this device, so you can compare before and after.

What to do with the result

  • Only one website fails: the problem is likely on that site; try later or from another network.
  • DNS fails: look at DNS settings or the modem, and bring the check result when you contact your provider.
  • High variation: run Deep Check in different rooms and at different times to find a pattern.
  • Everything fails: the modem, router or provider is the likely culprit; your check history is useful evidence for support.

Frequently asked questions

My iPhone is on Wi-Fi but nothing loads. What's wrong?

Common causes are DNS failures, TLS failures or the website itself. Run a Check in WiFi Aid Lite to see DNS, TCP and TLS results and which hop is failing.

How do I test an internet connection that keeps dropping?

Use Deep Check to collect more stability samples and see latency variation, then compare runs in your check history.

Is it one website or my whole network?

Use Check a Website to test that site against the wider internet.

Is WiFi Aid Lite a speed test app?

No. It focuses on finding the cause of a problem through DNS, TCP, TLS, TTFB, HTTP, latency and stability evidence.
